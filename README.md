# 🐾 Sniff-N-See

A delightful React application for browsing dog breeds, viewing images, and learning about different dogs.

## ✨ Features

- **Browse Dog Breeds**: Search and explore a comprehensive list of dog breeds
- **Image Gallery**: View multiple high-quality images of your selected breed
- **Breed Details**: Access information about temperament, life span, and other breed characteristics
- **Breed Comparison**: Compare multiple breeds side-by-side to help with your decision
- **Breed Matcher Quiz**: Take a lifestyle quiz to find your perfect canine companion
- **Care Guides**: Access detailed care information for each breed (nutrition, exercise, grooming, etc.)
- **Favorites**: Save your favorite dog images for future reference
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices

## 🛠️ Technologies

- **React 18**: Functional components with hooks
- **CSS Modules**: For component-based styling
- **React Icons**: For beautiful UI elements
- **Dog CEO API**: For breed data and images
- **Local Storage**: To persist favorites

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/your-username/sniff-n-see.git
cd sniff-n-see
```

2. **Install dependencies**

```bash
npm install
# or
yarn install
```

3. **Start the development server**

```bash
npm start
# or
yarn start
```

4. **Open your browser**

Visit [http://localhost:3000](http://localhost:3000) to see the app in action.

## 📱 App Usage Guide

### Finding a Breed

1. Navigate to the **Browse Breeds** tab
2. Use the search field to find a specific breed or browse the dropdown
3. Select how many images you'd like to view (1-10)
4. Click "Fetch Dogs" to display the images

### Using the Breed Matcher Quiz

1. Go to the **Breed Matcher Quiz** tab
2. Click "Start Quiz"
3. Answer the 10 questions about your lifestyle and preferences
4. Review your top matches and click "View Breed" to see more details

### Comparing Breeds

1. From the Browse tab, select a breed and click "Add to Comparison"
2. Repeat for multiple breeds
3. Go to the **Compare Breeds** tab to see a side-by-side comparison

### Accessing Care Guides

1. Navigate to the **Care Guides** tab
2. Select a breed from the dropdown
3. Browse through the nutrition, exercise, grooming, health, and training information
